# YEPI logo pack — web

Colours: Deep Navy #0B1F4F · Path Blue #1769FF · Growth Mint #1DE59A · White #FFFFFF
Font: Archivo (Google Fonts). Text in the SVGs is outlined — no font needed.

svg/      Master vector logos — use on the website wherever possible
  yepi-horizontal.svg            primary, on light backgrounds
  yepi-horizontal-reversed.svg   on navy / dark backgrounds (transparent)
  yepi-stacked(-reversed).svg    square / narrow spaces
  yepi-mark(-reversed).svg       icon only
  yepi-wordmark(-white).svg      type only
  yepi-endorsed-horizontal(-reversed).svg   logo + "A programme of Wisdom for Business Conference 2026"
  yepi-endorsed-stacked(-reversed).svg      same, stacked
  yepi-endorsement-only(-white).svg         the endorsement text block on its own
png/      Transparent PNGs, 480 / 960 / 1920 px wide; marks 64–1024 px
favicon/  Drop into the site root
social/   og-image-1200x630.png (link previews), profile-avatar-800.png

Paste in <head>:
<link rel="icon" href="/favicon.ico" sizes="any">
<link rel="icon" href="/favicon.svg" type="image/svg+xml">
<link rel="apple-touch-icon" href="/apple-touch-icon.png">
<link rel="manifest" href="/site.webmanifest">
<meta property="og:image" content="/og-image-1200x630.png">
<meta name="theme-color" content="#0B1F4F">

Rules: min width 160px (horizontal), 24px (mark). Clear space = arrowhead width.
On navy use the reversed versions — never the colour mark on dark backgrounds.

Use an endorsed version on all external comms (website header/footer, partner pages).
If the official Wisdom for Business logo is supplied, it replaces the typeset name.
